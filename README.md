## 📌 คุณสมบัติของโปรแกรม (Features)

* **รับข้อมูลผ่านไฟล์ `.txt`:** อ่านข้อมูลตารางโซดุกุขนาด 9x9 ผ่านไฟล์ข้อความอย่างถูกต้อง
* **ตรวจจับและจัดการกรณีพิเศษครบถ้วน:**
  * **NO SOLUTION:** แจ้งเตือนเมื่อโจทย์มีตัวเลขขัดแย้งกันเองตั้งแต่ต้น หรือไม่สามารถหาคำตอบที่ถูกต้องตามกฎได้[cite: 1]
  * **MULTIPLE SOLUTIONS:** แจ้งเตือนเมื่อโจทย์ระบุตัวเลขน้อยเกินไปจนมีคำตอบได้มากกว่า 1 รูปแบบ[cite: 1]
  * **COMPLETED:** ตรวจสอบความถูกต้องและคืนค่าตารางเดิมหากโจทย์ที่นำเข้ากรอกตัวเลขครบสมบูรณ์อยู่แล้ว[cite: 1]
* **รองรับการรัน 2 รูปแบบ:** รันผ่าน Command Line Interface (CLI) และหน้าเว็บอินเทอร์เฟซ (Streamlit)[cite: 1]
* **ตารางแสดงผลแบบ Custom HTML:** แสดงผลตาราง 9x9 พร้อมเน้นเส้นขอบบล็อก 3x3 จัดตัวเลขกึ่งกลางชัดเจน ไม่ติดหัวตาราง และกดคลิกแก้ไขไม่ได้

## 🧠 หลักการและแนวคิดอัลกอริทึม (Algorithm Concept)

โปรแกรมพัฒนาขึ้นโดย **ไม่อาศัยไลบรารีสำเร็จรูปสำหรับแก้โซดุกุ**[cite: 1] โดยใช้แนวคิดทางคณิตศาสตร์และคอมพิวเตอร์ ดังนี้:

1. **Constraint Satisfaction (การตรวจสอบเงื่อนไข):**
   * แต่ละช่อง $9 \times 9$ จะต้องถูกเติมด้วยตัวเลข 1–9
   * เงื่อนไขบังคับ: ตัวเลขต้องไม่ซ้ำกันใน **แถวเดียวกัน**, **หลัก (Column) เดียวกัน** และ **บล็อกย่อย $3 \times 3$ เดียวกัน**[cite: 1]
2. **Backtracking Search (การค้นหาแบบย้อนกลับ):**
   * โปรแกรมจะค้นหาช่องว่าง (เลข `0`) ในตารางทีละช่อง[cite: 1]
   * ทดลองใส่ตัวเลข 1–9 ที่สอดคล้องกับเงื่อนไข แล้วเรียกตัวเองแบบ Recursion เพื่อเดินหน้าต่อ
   * หากเจอทางตัน โปรแกรมจะทำการ Backtrack ถอยกลับมาเปลี่ยนตัวเลขช่องก่อนหน้า[cite: 1]
3. **Multiple Solutions Detection (นับจำนวนคำตอบ):**
   * อัลกอริทึมถูกออกแบบให้ค้นหาคำตอบอย่างน้อย 2 ชุด[cite: 1]
   * หากพบคำตอบแรกจะเก็บไว้ในหน่วยความจำ และค้นหาต่อทันที หากพบคำตอบที่ 2 จะหยุดการคำนวณและส่งคืนผลลัพธ์ว่า `MULTIPLE SOLUTIONS` ทันทีเพื่อประสิทธิภาพสูงสุด[cite: 1]
